# Vincos & Agulha — Projeto Completo V1.0

Aplicação online para gestão de produção de engomadoria.

## Inclui
- Login por código e senha
- Gerente cria clientes e funcionários
- Código de acesso e senha inicial
- Troca obrigatória de senha no primeiro acesso
- Registo de número de peças por cliente
- Dashboard por cliente e funcionário
- Histórico e exportação CSV/Excel
- Projeto React/Vite pronto para Vercel
- Script Supabase pronto em `supabase/schema.sql`

## Publicação
1. Execute `supabase/schema.sql` no Supabase.
2. Envie o projeto para GitHub.
3. Na Vercel, importe o repositório.
4. Configure:
   - VITE_SUPABASE_URL
   - VITE_SUPABASE_ANON_KEY
5. Deploy.
